# Tic-Tac-Toe

A browser-based tic-tac-toe game in a single self-contained HTML file — no build step, no dependencies.

## How to play

Open `index.html` in any browser.

- **2 Players** — X and O take turns on the same device.
- **vs Computer** — you play X; the computer plays O using the minimax algorithm, so it never loses.

The winning line is highlighted, and a running score of X wins, O wins, and draws is kept across rounds. Click **New Round** to play again.
